# 🌐 Windows Network Basics

> 사내 IT 운영 직무에 필요한 Windows 네트워크 기초(IP, DNS, DHCP)를 학습하고,
> Windows 명령어를 활용한 네트워크 점검 및 장애 진단 과정을 정리한 저장소입니다.

---

## 📖 About

이 저장소는 사내 IT 운영 및 기술지원 직무를 준비하며
Windows 환경에서 기본적으로 알아야 하는 네트워크 개념과
실습 내용을 기록하기 위해 만들었습니다.

단순히 이론을 정리하는 것이 아니라
직접 Windows 명령어를 실행하고 결과를 분석하며
실무에서 활용할 수 있는 형태로 학습하는 것을 목표로 합니다.

---

## 🎯 Learning Goals

- IP 주소의 개념과 사설 IP / 공인 IP 이해
- Subnet Mask와 Default Gateway의 역할 이해
- DNS 동작 원리 및 이름 해석 과정 이해
- DHCP를 통한 자동 IP 할당 과정 이해
- Windows 네트워크 명령어 활용
- 기본적인 네트워크 장애 진단 방법 익히기

## 🧪 Practice

실습은 Windows 환경에서 직접 수행합니다.

- `ipconfig`
- `ipconfig /all`
- `ping`
- `tracert`
- `nslookup`
- `ipconfig /release`
- `ipconfig /renew`
- `ipconfig /flushdns`

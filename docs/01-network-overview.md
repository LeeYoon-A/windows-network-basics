# 🌐 Network Overview

## 📖 What is a Network?

네트워크(Network)는 여러 장치가 서로 연결되어 데이터를 주고받을 수 있는 환경을 의미합니다.

---

## 🖥️ How does the Internet work?

사용자가 웹사이트에 접속하면 데이터는 다음 순서로 이동합니다.

```text
My PC
   ↓
Router (Gateway)
   ↓
Internet
   ↓
Server
   ↓
My PC
```

---

## 🔑 Key Components

| Component | Role |
|-----------|------|
| IP Address | 장치의 주소 |
| Gateway | 외부 네트워크로 나가는 출구 |
| DNS | 도메인 이름을 IP 주소로 변환 |
| DHCP | IP 주소를 자동으로 할당 |

---

## 💼 In Practice

IT 운영에서는 네트워크 장애가 발생하면

1. IP 확인
2. Gateway 확인
3. DNS 확인

순서대로 점검합니다.

---

## ✅ What I Learned

네트워크 통신은

**IP → Gateway → Internet → Server**

순서로 이루어진다는 것을 이해했습니다.

---

## 🎤 Interview Answer

### Q. 네트워크(Network)란 무엇인가요?

> 네트워크는 여러 장치가 데이터를 주고받기 위해 연결된 환경입니다.  
> 인터넷 통신은 일반적으로 **PC → Gateway → Internet → Server** 순서로 이루어지며, 이 과정에서 **IP는 장치의 주소**, **DNS는 도메인 이름을 IP 주소로 변환**, **DHCP는 IP 주소를 자동으로 할당**하는 역할을 합니다.
